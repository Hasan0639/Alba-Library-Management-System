# ALBA Library Management System

The ALBA Library Management System is a web-based system developed for Aluminium Bahrain (ALBA) to manage books, borrowing, returns, and library resources within the organization.

## Features
- User login
- Admin and user roles
- Add, edit, and delete books
- Search books
- Borrow and return books
- Manage book categories
- Track available copies

## Technologies Used
- React.js
- PHP
- MySQL
